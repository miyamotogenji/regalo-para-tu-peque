# Publicar en WordPress (File Manager / cPanel)

El hosting Banahosting estuvo inaccesible desde nuestra red (timeout al servidor).
Estos ZIP están listos para subir apenas tengas acceso a File Manager.

## Proyecto 2 — Formulario «Un regalo para tu peque»
1. Subí `un-regalo-para-tu-peque.zip` a `public_html/`
2. Extraelo ahí (queda la carpeta `un-regalo-para-tu-peque`)
3. URL: `https://todosabordocr.com/un-regalo-para-tu-peque/`
4. En **Recursos gratis**, cambiá el botón DESCARGAR de “Potenciá su cerebro” a esa URL

Alternativa Elementor: pegá `elementor-html-widget.html` en un widget HTML.
Plugin: `todos-regalo-form.zip` → Plugins → Subir → Activar.

## Proyecto 3 — Landing «El Poder de Ser Yo»
1. Subí `el-poder-de-ser-yo.zip` a `public_html/`
2. Extraelo (queda la carpeta `el-poder-de-ser-yo`)
3. URL: `https://todosabordocr.com/el-poder-de-ser-yo/`
4. Incluye `submit-inscripcion.php` + `brevo-config.php` (lista Brevo #9)
